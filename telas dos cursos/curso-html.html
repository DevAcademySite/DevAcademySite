O que é HTML?

HTML (HyperText Markup Language) é a linguagem que descreve o conteúdo de uma página: o que é título, o que é parágrafo, o que é link e o que é imagem. Todo site da internet começa por ele.

HTML: a estrutura

São as paredes e os cômodos da casa. Define o que existe na página.

CSS: o visual

É a pintura e a decoração. Define cores, fontes e a posição de cada coisa.

JavaScript: o comportamento

É a parte elétrica. Faz botões, menus e formulários realmente funcionarem.
